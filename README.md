# EA MT5 Professional - Technical & Fundamental Separation Final

Automated Trading EA for MT5 with separated Technical and Fundamental Analysis engines.

## Features
- Smart Money Concept (SMC)
- Liquidity Sweep Detection
- Break of Structure (BOS)
- Fundamental News Analysis (High Impact Only)
- Spike Filter System
- ATR Trailing Stop
- Multi-broker Support (HFM, Exness, DooPrime, Markets4you, etc.)
